# ВКР: Разработка системы автоматизированного контроля состава отходящих газов печи Ванюкова с использованием газоанализаторов

Данная папка содержит **черновик-шаблон** выпускной квалификационной
работы бакалавра по направлению **15.03.04 «Автоматизация технологических
процессов и производств»**, подготовленный с учётом материалов
методических указаний, образцов оформления ПЗ и примеров ВКР,
размещённых в репозитории `Для_ВКР/`.

## Состав папки

| Файл | Назначение |
|---|---|
| `ВКР_Печь_Ванюкова.md` | Основной текст пояснительной записки в формате Markdown (≈70 страниц при конвертации) |
| `ВКР_Печь_Ванюкова.docx` | Текст пояснительной записки в формате Word (формируется через `make docx`) |
| `simulink/params.m` | Скрипт MATLAB для расчёта параметров модели и ПИ-регулятора |
| `simulink/SO2_loop.slx.README.md` | Описание структуры модели Simulink (сам файл `.slx` собирается студентом) |
| `README.md` | Текущий файл |

## Структура работы

В соответствии с «Образцом оформления ПЗ ВКР 15.03.04» (см.
`Для_ВКР/Образец оформления ПЗ ВКР 15.03.04 (1).pdf`) ПЗ имеет
следующую структуру:

- Титульный лист
- Задание на ВКР
- Аннотация
- Перечень условных обозначений
- Содержание
- Введение
- **1 Технологический раздел** (1.1–1.5)
- **2 Раздел автоматизации** (2.1–2.5)
- Заключение
- Список использованных источников (≥ 20 наименований, преимущественно
  свежих)
- Приложение А. Спецификация ТСА
- Приложение Б. Расчёт экономической эффективности
- Приложение В. Листинг моделей Matlab/Simulink
- Приложение Г. БЖД и охрана окружающей среды

## Что нужно сделать студенту перед сдачей

1. **Заполнить плейсхолдеры** вида `______________________`:
   ВУЗ, факультет, кафедра, профиль, ФИО студента и руководителя,
   группа, год, наименование предприятия (по преддипломной практике).
2. **Уточнить технологические данные** (производительность,
   составы концентрата и штейна, расходы, температуры) на материалах
   преддипломной практики и согласовать с руководителем.
3. **Сверить выбор ТСА** с руководителем — в шаблоне предложено
   решение на отечественной элементной базе (ОВЕН ПЛК 210,
   MasterSCADA 4D, газоанализаторы АО «ОПТЭК»). При необходимости
   заменить на оборудование, утверждённое кафедрой.
4. **Собрать модель Simulink** `SO2_loop.slx` по описанию в
   `simulink/SO2_loop.slx.README.md`, прогнать `params.m`,
   сохранить графики переходного процесса для графической части.
5. **Выполнить графическую часть** в Компас-3D или AutoCAD по ГОСТ
   21.408-2013 и ГОСТ 21.208-2013:
   - Лист 1. Схема функциональная автоматизации печи Ванюкова.
   - Лист 2. Структурно-функциональная схема КТС.
   - Лист 3. Схема функциональная контура регулирования + переходный
     процесс из Matlab/Simulink.
   - Лист 4. Блок-схема алгоритма автокалибровки газоанализаторов.
6. **Согласовать раздел экономики** с консультантом по экономической
   части (Приложение Б) и **раздел БЖД** с консультантом по
   безопасности жизнедеятельности (Приложение Г).
7. **Перенести текст в шаблон Word** с рамками ГОСТ из
   `Для_ВКР/Образец оформления ПЗ ВКР 15.03.04/`. Шрифты GOST type A
   и B уже находятся в папке `Для_ВКР/Шрифты/` — установить их
   в Windows перед открытием шаблона, иначе рамки будут отображаться
   некорректно.
8. **Проверить уникальность** в системе антиплагиата ВУЗа и при
   необходимости переформулировать общие фразы своими словами.
   Шаблон содержит много типового технического текста, который
   обязательно нужно адаптировать.

## Конвертация в Word/PDF

Из Markdown в .docx через pandoc:

```bash
pandoc ВКР_Печь_Ванюкова.md \
    -o ВКР_Печь_Ванюкова.docx \
    --reference-doc=../Образец\ оформления\ ПЗ\ ВКР\ 15.03.04/Образец\ оформления\ ПЗ\ ВКР\ 15.03.04.docx \
    --standalone \
    --toc --toc-depth=3
```

> Если файла `Образец оформления ПЗ ВКР 15.03.04.docx` нет — pandoc
> сгенерирует .docx со стилями по умолчанию, после чего форматирование
> придётся настраивать вручную.

В PDF (через TeX Live + xelatex):

```bash
pandoc ВКР_Печь_Ванюкова.md -o ВКР_Печь_Ванюкова.pdf \
    --pdf-engine=xelatex \
    -V mainfont="Times New Roman" \
    -V geometry:"left=30mm, right=15mm, top=20mm, bottom=20mm" \
    -V fontsize=14pt \
    -V linestretch=1.5 \
    --toc --toc-depth=3
```

## Дисклеймер

Текст работы является **черновиком-шаблоном**, подготовленным
автоматически на основе общедоступных учебных материалов
и методических указаний. Финальный вариант должен быть
самостоятельно адаптирован студентом, подкреплён фактическими
данными преддипломной практики и согласован с научным руководителем.
Без такой адаптации работа не пройдёт нормоконтроль и проверку
на оригинальность.
